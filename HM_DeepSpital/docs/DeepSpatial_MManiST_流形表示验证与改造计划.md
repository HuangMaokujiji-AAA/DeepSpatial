# DeepSpatial × MManiST：欧氏–双曲联合表达表示的验证与三维重建改造计划

> 研究主题：在稀疏空间转录组多切片三维重建中，验证欧氏–双曲联合表达嵌入能否改善低丰度（稀有）细胞的跨切片匹配，并进一步改善其数量、位置和表达恢复。  
> 文件性质：**研究假设与实施计划，非已验证的实验结论**。  
> 版本：V1.0｜2026-10-28

---

## 0. 摘要与决策原则

本项目以 **DeepSpatial** 为三维重建基线，借鉴 **MManiST** 的欧氏与双曲空间多视图编码思想，但**不将 MManiST 直接当作三维重建基线**。MManiST 原任务是空间域识别；DeepSpatial 的 GiT 内部虽然有 Transformer 隐藏 Token，但原始方案没有独立的低维基因表达自编码器瓶颈。因此，不能把双曲编码器简单替换成“DeepSpatial 原有潜空间”。

核心研究假设按因果顺序拆开：

- **H1（表示假设）**：与同等容量的欧氏嵌入相比，欧氏–双曲联合嵌入能在跨切片条件下更好地区分低丰度细胞的表达状态。
- **H2（配对假设）**：将经验证的联合嵌入引入 UOT 的**表达代价项**，可减少稀有细胞跨切片错误耦合，同时不显著损害常见细胞匹配。
- **H3（重建假设）**：更好的 UOT 耦合能够在**不更改原始 GiT/Flow Matching 主干**的情况下改善隐藏切片稀有细胞的数量、空间位置和表达恢复。
- **H4（可选扩展）**：若 H1–H3 成立但仍存在表达状态偏移，再尝试生成端的细胞类型条件流形一致性正则化。

**先验证 H1，再验证 H2，最后验证 H3。任何一步失败，都应保留否定结果，而不是叠加复杂模块掩盖问题。**

### 0.1 研究边界

1. 不声称“稀有细胞一定具有双曲结构”，该结构是否有益必须通过实验检验。
2. 不将 Poincaré 与 Lorentz 当作两种独立生物学先验：二者本质上是双曲空间的不同模型；初版先用一种双曲模型，后续再比较参数化稳定性。
3. 不把空间域标签（如 DLPFC cortical layer）当作稀有**细胞类型**标签。
4. 不将任意 z 位置的连续预测，理解为单个细胞发生真实发育或迁移的轨迹。
5. 不把“生成结果的 UMAP 分群更清晰”视作稀有细胞成功恢复的证据；以真实隐藏切片为最终检验。

## 1. 原始方法核查与拟改造位置

| 维度 | DeepSpatial（原始框架） | MManiST（原始框架） | 对本研究的含义 |
|---|---|---|---|
| 主要任务 | 多切片连续三维空间组学重建 | ST 空间域识别 | 不可直接比较两者“重建分数” |
| 输入 | 坐标、表达、可选细胞类型及切片元数据 | 表达与空间 KNN 图 | 联合编码器应接受训练切片的细胞/spot 表达与图 |
| 表示方式 | 基因表达 Patch Token 与 Transformer 隐藏特征 | 欧氏、Poincaré、Lorentz 图表示 | 两者原有“潜空间”不是同一对象 |
| 跨切片关系 | UOT 耦合 | 原文不针对跨切片表达生成 | 优先把新表示接入 UOT 的表达代价 |
| 生成过程 | GiT/Flow Matching，ODE 推理 | 无三维连续生成 | 第一版严格冻结生成主干设计 |
| 优化目标 | 联合状态速度学习等 | 多分支重建与 Pareto/MGDA | 第一版不照搬全部 MManiST 优化策略 |

**优先插入点 A（推荐）**：表达矩阵 → 共享嵌入编码器 → 跨切片表达距离 → UOT 代价矩阵 → 原始 GiT 训练与重建。

**候选插入点 B（延期）**：在生成结果上添加独立的类型条件表达几何约束；只在 H1–H3 有依据时尝试。

## 2. 数据集与可评价性审计（Phase 0）

### 2.1 数据集优先级

| 层级 | 数据候选 | 用途 | 进入稀有细胞主实验的必要条件 |
|---|---|---|---|
| 主数据集 | DeepSpatial 官方 MERFISH mouse hypothalamus 多切片示例，或已有的同类 MERFISH 多切片数据 | 先复现官方输入管线，再执行隐藏切片验证 | 真实有序 z、可比基因集合、可信细胞类型标签、各切片有可检测稀有类 |
| 外部验证 | 另一份具有高分辨率细胞标签的多切片 MERFISH / Xenium / 类似数据 | 验证跨组织/平台泛化 | 单细胞级观测或可靠 cell type 注释、真实邻接切片 |
| 方法调试 | MManiST 使用的 DLPFC 示例 | 检查编码器可运行，观察几何表示学习 | **不**以 layer 标签作为稀有细胞恢复的最终证据 |

如果官方 MERFISH 只有少量切片，可先完成管线及探索实验；但统计独立性可能不足，最终显著性与泛化结论需更多独立组织、动物或样本支持。

### 2.2 数据清单与统一格式

每张切片使用 `AnnData` 存储，并建立独立元数据表：

- `adata.X`：原始计数（如可获得，保留 `layers['counts']`）和规范化表达。
- `adata.obsm['spatial']`：二维细胞中心坐标，统一物理尺度或注明像素尺度。
- `adata.obs['slice_id']`、`z_um`：切片编号及实际 z 坐标；缺失物理厚度时只允许使用归一化顺序，并标注局限。
- `adata.obs['cell_type']`：经 QC 的参考细胞类型标签；原生无标签时单独开展标签推断，记录其误差与不确定性。
- `adata.var_names`：经过**训练集决定**的对齐基因列表；不得用隐藏切片筛选 HVG、设定均值方差或选择稀有 marker。
- 每个细胞/spot 的唯一 ID、样本 ID、切片 ID、来源文件、分辨率与坐标系说明。

**预处理防泄露规则**：以训练切片拟合归一化统计量、基因筛选、PCA/AE、图编码器及所有超参数；隐藏切片只在最终评价时提供表达和位置。若参考 scRNA-seq 独立于隐藏切片，可以用于训练，但必须声明来源与标签使用范围。

### 2.3 稀有细胞的预注册定义

优先依据可信的真实 cell-type annotation，而不是根据生成结果划定稀有类。建议开展三种分层：

| 稀有度层级 | 建议定义（探索性阈值） | 解释 |
|---|---|---|
| 极低丰度 | 训练可见切片总体比例 `<1%` | 高不稳定性；必须报告细胞数及是否有足够验证样本 |
| 低丰度 | `1%–5%` | 主要稀有类分析 |
| 非稀有对照 | `>5%` | 检验整体性能是否下降 |

阈值仅为初始建议，最终应根据实际标签统计和样本数量**预先固定**，避免事后挑选；同时报告各类型在**每张切片**上的数量。类型在某些切片完全缺失时，应单列“出生/消失/未检出”场景，不能将不存在的真实细胞当作应该恢复的目标。

另做**同数量下采样对照**：从常见类型抽取与稀有类型相近的训练数量，区分“低样本量问题”和“特殊表达几何问题”。

### 2.4 隐藏切片设计

主要评价采用真实中间切片的 leave-middle-slice-out：

```text
完整真实数据：S1 — S2 — S3 — S4 — S5
实验示例：    训练可见 S1,S2, S4,S5；隐藏 S3
模型必须仅依据可见切片重建 z(S3)，再用真实 S3 评价。
```

进一步分层测试：

1. **正常间距**：隐藏 1 张中间切片。
2. **大间距压力测试**：隐藏连续 2 张或更多切片（前提是剩余切片数和物理距离满足可评价性）。
3. **跨样本测试**：能获得多组织/生物学重复时，按样本或动物分组留出，避免同一样本信息污染独立验证。
4. **空间稀有热点测试**：在隐藏切片中评估稀有细胞富集区域，不只看全切片平均值。

**嵌套划分**：训练 / 验证 / 最终测试以切片或生物样本为单位；先用验证集调参，再一次性冻结方案评价最终测试。不能在同一个隐藏切片上反复选参又声称无偏测试。

## 3. 表示能力独立验证（Phase 1：不修改 DeepSpatial）

### 3.1 目标

直接回答 H1：**双曲表示是否比容量可比的欧氏表示更有利于稀有细胞判别、邻域结构保留与跨切片匹配？**

此阶段不运行 DeepSpatial 完整生成器，只训练独立表示编码器，然后在**未见过的真实切片**上评估。

### 3.2 对照组

| 编号 | 编码器/距离 | 控制要点 |
|---|---|---|
| E0 | PCA / 简单 AE + Euclidean distance | 简单基线，控制训练及计算开销 |
| E1 | 欧氏图自编码器（GCN/GAT） | 与双曲编码器相近参数规模、邻居图和维度 |
| H1 | Poincaré 双曲图编码器 | 固定正曲率参数 `c` 的候选值，注意数值稳定性 |
| EH1 | 欧氏图编码器 + Poincaré 编码器的融合 | 首选简单拼接/归一化加权，不首先引入复杂注意力 |
| EH2（可选） | 欧氏 + Poincaré + Lorentz | 只用于验证额外参数化是否真的增加收益 |
| E1-balanced（必要） | E1 + 稀有类型重加权或均衡采样 | 排除改进仅源于类别平衡，而非双曲几何 |

**公平性**：输入基因、预处理、KNN 构图、训练可见切片、随机种子、优化步数和尽量接近的参数量一致。Poincaré 与 Lorentz 本质上是同一负曲率几何的不同参数化，不能把两者融合本身解释为“生物学多模态发现”。

### 3.3 训练约束

- 初版编码器训练仅使用**训练可见切片**；空间图只在已观测的真实同张切片内部构建，避免用隐藏切片坐标搭图。
- 输出维度推荐测试 `d ∈ {16, 32, 64}`；每组固定随机种子 `{0, 1, 2, 3, 4}`（具体数量随算力调整，但各组完全一致）。
- 双曲模型选择 Poincaré：从稳定的小曲率网格开始，采用成熟的 geoopt 等流形优化组件；记录到边界的距离、NaN/Inf、梯度范数和有效曲率。
- 嵌入训练优先从**无细胞类型标签监督**开始，保证改进不是直接来自标签泄露；若额外采用类型监督，作为独立实验臂并明确标注。
- 训练后固定编码器，只使用训练定义的投影/映射提取验证切片表示，不在验证/测试上重拟合。

### 3.4 几何距离

欧氏：

\[
d_E(i,j)=\|h_i^E-h_j^E\|_2
\]

Poincaré ball（曲率 \(-c\)，\(c>0\)）：

\[
d_{\mathbb B_c}(u,v)=\frac{1}{\sqrt c}\operatorname{arcosh}\!\left(1+\frac{2c\|u-v\|_2^2}{(1-c\|u\|_2^2)(1-c\|v\|_2^2)}\right).
\]

注意严格的范数约束 \(c\|u\|^2<1\)，在实际实现中设置安全边界并裁剪数值误差。采用距离尺度标定（例如训练配对的稳健中位数/IQR）后再混合，防止一个距离因量纲大而垄断 UOT。

### 3.5 Phase 1 指标与解释

| 指标 | 定义/实现 | 能说明什么 | 注意事项 |
|---|---|---|---|
| 稀有类 macro-AUPRC | 在冻结嵌入上训练相同线性/轻量 probe，按稀有类计算 PR-AUC 再宏平均 | 稀有类别能否被区分 | 探针只在训练切片拟合；报告每类 prevalence |
| 稀有类 macro-F1 / Recall | 冻结 probe 在留出切片预测 | 低丰度细胞的可识别性 | 阈值只从验证集选定 |
| 类型条件 kNN purity | \(\frac{1}{|R|}\sum_{i\in R}\frac{1}{k}\sum_{j\in N_k(i)}1[y_j=y_i]\) | 同类型邻域结构是否更稳定 | 邻域及候选库均用明确可比的真实细胞集；k 多尺度 |
| Cross-slice retrieval@k | 对训练/验证可比切片，根据表达表示检索同类型候选，计算 top-k 命中率 | 能否帮助跨切片匹配 | 这是**类型一致性代理指标**，并非真实逐细胞配对准确率 |
| Rare-class coverage | 参考真实稀有细胞的表示有多少落入生成/候选嵌入支持域（固定阈值或 kNN 密度） | 表示对稀有状态的覆盖 | 阈值在训练数据校准；不以 UMAP 视觉判断 |
| 计算开销与稳定性 | 训练/推理时长、峰值显存、NaN 比率 | 能否工程落地 | 必须报告以防复杂模型性价比过低 |

**关键解释**：没有真实跨切片细胞对应 ID 时，`retrieval@k` 只能判断**类型层面匹配合理性**，不能声称恢复了单细胞真实谱系对应关系。若有配对标注或配准锚点，额外报告真实匹配的 top-1 / top-k。

### 3.6 假设与诊断性负对照

- **类别平衡对照**：欧氏编码器也使用相同稀有类重采样或重加权，排除“类别不均衡被修复”冒充双曲几何优势。
- **图消融**：表达 KNN vs 空间 KNN；若空间图导致稀有细胞被常见邻居平滑，尝试减小 k 或保留自环。
- **标签置换负对照**：在仅作为 probe 的标签上置换训练标签，判别分数应接近相应随机基线。
- **曲率退化检测**：如果双曲分支趋近欧氏效果、优势仅来自参数量或优化配置，应记录为未支持几何假设。
- **不平衡敏感性**：按稀有度层级、细胞总数和每层丰度分析增益，而非只看宏平均。

### Phase 1 晋级门槛（建议预注册，而非论文已证明阈值）

1. `EH1` 相对**最佳同容量欧氏对照**在验证数据上的稀有类 macro-AUPRC 获得**至少 +0.03 绝对增量**，并在多数独立切片/样本对中方向一致；数值是可调整的初始门槛。
2. 同时 `cross-slice retrieval@k` 或稀有类邻域纯度改善；不能只改善 UMAP 分离度。
3. 常见类 macro-F1、整体类别准确性没有预注册不可接受的下降（例如 > 0.02 绝对值）。
4. 数值稳定、显存/训练时长仍可承担；若收益小于变异或无法重现，**停止双曲路线**，保留普通欧氏编码器结果。

## 4. UOT 跨切片耦合改造（Phase 2：只修改代价）

### 4.1 基础策略

保留原始 DeepSpatial UOT 约束、求解器、下游 GiT、Flow Matching loss、采样与密度机制，**只替换或增加 UOT 代价矩阵中的表达距离部分**。

原始代价可概念化为：

\[
C^{\rm base}_{ij}=\lambda_s C^{\rm spatial}_{ij}+\lambda_g C^{\rm expr}_{ij}+\lambda_c C^{\rm type}_{ij}.
\]

> 上式是研究规划层面的结构化抽象，代码实现前必须核查当前仓库真实代价项、归一化以及权重处理，不得据此假定源码的函数签名。

联合距离候选：

\[
C^{\rm mani}_{ij}=\alpha\,\widetilde d_E(h_i^E,h_j^E)^2 + (1-\alpha)\,\widetilde d_H(h_i^H,h_j^H)^2.
\]

只改变表达项：

\[
C^{\rm new}_{ij}=\lambda_s C^{\rm spatial}_{ij}+\lambda_g C^{\rm mani}_{ij}+\lambda_c C^{\rm type}_{ij}.
\]

其中 \(\widetilde d_E\) 与 \(\widetilde d_H\) 在**训练切片**上做稳健尺度标定；\(\alpha\in\{0,0.25,0.5,0.75,1\}\) 在验证集选择。为了防止新代价与原始代价尺度差异主导结果，还应比较保留原始表达代价的混合：

\[
C^{\rm expr\mbox{-}blend}=(1-\beta)C^{\rm expr}_{\rm base}+\beta C^{\rm mani},\quad \beta\in[0,1].
\]

正式实验应从此**保守 blend 方案**开始。若原 UOT 已有类型惩罚，保持不变并单独消融，避免类型信息在编码器和代价中重复造成“标签捷径”。

### 4.2 代码改造原则

1. 从 DeepSpatial 真实源码搜索 UOT 代价构造入口（关键词：`uot`, `cost`, `expression`, `coupling`, `transport`），记录**实际文件路径与函数名**；本计划不虚构文件路径。
2. 实现 `ExpressionCostProvider` / 等价轻量接口：`base`, `euclidean_embed`, `hyperbolic_embed`, `euclidean_hyperbolic`。
3. 从**冻结编码器**缓存每张训练切片的嵌入，仅为当前训练切片对计算跨切片成本。
4. UOT 求解器及其超参数在第一轮改造保持不变；仅在确认新代价影响后做独立调参。
5. 保存 UOT 耦合的摘要、稀疏索引与权重；不盲目保存巨大的完整密集矩阵。
6. 输出 `config.yaml`、数据 split 清单、seed、Git commit 和指标文件，保证比较可重跑。

伪代码（**并非官方 API**）：

```python
# 伪代码：仅表达设计，不代表 DeepSpatial 已有这些类
train_slices = load_visible_slices(split)
encoder = load_frozen_joint_encoder(checkpoint)

    C_base = original_cost_components(left, right)
    C_emb = calibrated_manifold_cost(emb[left], emb[right], alpha=cfg.alpha)
    C_expr = (1 - cfg.beta) * C_base.expr + cfg.beta * C_emb
    C_new = C_base.with_expression_cost(C_expr)
    coupling = original_uot_solver(C_new, config=cfg.original_uot)
    cache_coupling(left, right, coupling)

# GiT/Flow Matching/ODE 严格使用未修改的原始实现
fit_original_git_using_cached_couplings()
```

### 4.3 UOT 配对诊断（比直接看最终指标更重要）

| 诊断指标 | 计算方法 | 主要风险 |
|---|---|---|
| 稀有类型同类传输质量占比 | 以已知训练切片标签计算稀有源细胞传往同类目标细胞的耦合质量 / 稀有源细胞总传输质量 | 类型标签有误；不能将其等同于真实一对一对应 |
| 稀有→常见跨类传输比例 | 稀有源到常见目标的总传输质量占比 | 稀有细胞表达身份被混合 |
| 未匹配质量与稀有细胞丢失率 | UOT 各源/目标边缘质量变化，按细胞类型分组 | 改善同类比例但直接丢弃困难稀有细胞 |
| 耦合熵/集中程度 | 按源归一化的 coupling entropy | 过于扩散或过度尖锐 |
| 几何跨度 | 耦合质量加权的 xy 迁移距离，经过配准/尺度校准 | 表达改进可能破坏几何对应 |
| 代价成分分布 | spatial / expression / type 的分位数、梯度或权重 | 数值量纲使某项实际失效 |

**核心反例检查**：如果同类型耦合占比提高，但稀有细胞总质量大幅被 UOT 丢弃，则不能判定改造成功。需同时报告**传输覆盖率**与**匹配纯度**。

### Phase 2 晋级条件

- 相比原始 UOT 和欧氏嵌入对照，稀有同类型耦合质量更高，并且稀有未匹配质量没有明显恶化。
- 效果在多个训练切片对一致，不以单一切片或单个细胞类型得出结论。
- 空间跨度没有非生物学异常，UOT 优化正常收敛。
- 完成仅成本替换的独立消融，确认不是额外类型标签或成本归一化造成的提升。

## 5. 三维生成检验（Phase 3：重建隐藏切片）

### 5.1 统一实验矩阵

| 组别 | 表达代价 | GiT/Flow Matching | 目的 |
|---|---|---|---|
| D0 | 官方原始 UOT 表达代价 | 原始 | **最重要的 baseline** |
| D1 | 欧氏 AE/GCN 嵌入代价 | 原始 | 判断收益是否仅来自学习型嵌入 |
| D2 | 仅双曲嵌入代价 | 原始 | 检验负曲率是否单独有效 |
| D3 | 欧氏 + 双曲联合嵌入代价 | 原始 | **主改造模型** |
| D4 | D3，但去掉稀有类保护/均衡策略（若 D3 有） | 原始 | 区分几何和采样因素 |
| D5（可选） | D3 + 生成端流形一致性 | 修改 loss | **仅 H1–H3 成立后开启** |

注意 D0–D3 应使用相同 DeepSpatial 主干参数、原始 UOT 正则参数、训练 epoch、随机种子、生成采样数量和数据预处理。编码器的额外参数、训练时间与峰值显存必须单独记录。

### 5.2 主要评价指标

**不应只看 ARI/NMI 或全局表达相关性。主要终点必须覆盖稀有细胞数量、空间位置、表达三方面。**

#### A. 稀有细胞数量

对每类 \(c\)：

\[
\mathrm{RAE}_c=\frac{|\hat N_c-N_c|}{\max(N_c,1)}
\]

- \(N_c\)：真实隐藏切片的稀有细胞数；\(\hat N_c\)：生成切片经**同一个冻结分类器**得到的预测数量。
- 同时报告总生成细胞数、类型比例误差 \(|\hat p_c-p_c|\)、零生成类型比例、稀有类 Recall。
- 若 \(N_c=0\)，不要通过分母 1 把不存在类的 RAE 混入主宏平均；单独报告假阳性生成数量。

#### B. 稀有细胞空间位置

采用**细胞类型条件**的空间分布距离：

\[
W_c = W\!\left(P^{\rm true}_{XY\mid c},P^{\rm pred}_{XY\mid c}\right)
\]

可用 Wasserstein/Sinkhorn 近似，并在坐标注册到同一组织参考系、坐标尺度一致后计算；**归一化细胞质量的 W 只反映位置形状，必须与数量 RAE 共同报告**。另报：

- 稀有细胞热点区域 occupancy / IoU（在训练前固定网格尺寸或区域划分）。
- 到真实稀有细胞最近邻距离的分布（单位 µm），注意细胞数不同会影响此指标。
- 多尺度空间分布对比与最近组织边界的距离分布。

#### C. 稀有细胞表达

- Marker gene signature correlation（预先确定 marker 集，不使用测试切片选择）。
- 稀有细胞内基因表达均值/方差差异、与参考群体的 MMD 或分布 Wasserstein。
- Rare-state coverage / precision：冻结的真实表达空间编码器中，生成表达对真实稀有状态覆盖与生成异常状态比例。
- 低表达基因的非负性、稀疏性、零值比例、过度平滑程度（仅在与原始数据预处理尺度一致时比较）。

**不存在真实单细胞一一对应时，不能对生成细胞与真实细胞逐个算 Pearson/RMSE 后把它当作配对重建精度。** 可以在固定空间网格或类型条件群体层面比较表达。

#### D. 整体性能保护（Guardrails）

- 全部细胞的空间分布距离、细胞数和主流细胞类型丰度误差。
- 全局基因表达相关、空间聚类或域分数（若数据有可靠域标签）。
- 生成组织形态与切片边界一致性；不应出现明显穿出组织的细胞。
- 模型训练/推理开销。

### 5.3 统计分析与公平比较

- 最终统计单位优先使用**生物学样本/切片对**；细胞不是相互独立的生物学重复。
- 对每个 split 使用相同 seed 集合（建议至少 5 个），先计算每个 split/seed 的配对改变量。
- 报告各类型原始数量、每个 split 的原始分数与改变量、95% CI（按样本/切片分组 bootstrap）和效应量。
- 对多个稀有类型、多个指标的比较控制多重检验，或预先指定一个主要终点（例如稀有类类型条件空间 Wasserstein + 数量 RAE 的共同主终点）。
- 若数据只有一套 5 张切片，结果应界定为**探索性证据**，不把随机 seed 当作独立生物学重复。

### 5.4 推荐通过门槛（实验前定稿）

以主数据集验证集对 D0 作配对比较，建议初始门槛：

1. 稀有类数量 RAE 和类型条件空间 Wasserstein **至少各改善 5% 相对幅度**，或者在更有代表性的样本级统计检验中有稳定正向效应；这是计划阈值，不是预期事实。
2. 稀有 marker signature correlation 不下降，真实稀有表达状态覆盖率提升。
3. 整体结构、常见细胞丰度和表达指标不发生超过预设容忍范围的下降（建议先以 2%–5% 范围做敏感性分析）。
4. 改善不只局限一个稀有类型或一个隐藏 z；至少跨不同间距、不同切片/样本稳定。

## 6. 可选改造：生成端类型条件流形一致性（Phase 4，非 MVP）

**仅在 Phase 1–3 给出积极证据时启动。**

### 6.1 动机

即使 UOT 配对改善，Flow Matching 生成的表达仍可能偏离真实细胞表达状态。可在预测的**最终生成细胞**或合法的去噪估计上施加表达几何约束，避免直接强迫所有线性插值噪声状态处于真实流形内。

### 6.2 候选损失

冻结一个仅由训练数据/独立参考数据拟合的**类型条件表达分布估计器** \(p_\phi(h\mid c)\)，对解码/生成得到的最终表达 \(\hat g\) 求：

\[
\mathcal L_{\rm manifold}=\mathbb E_{(\hat g,c)}[-\log p_\phi(E(\hat g)\mid c)].
\]

总损失候选：

\[
\mathcal L=\mathcal L_{\rm DeepSpatial}+\lambda_m\mathcal L_{\rm manifold}.
\]

说明：

- 这是**研究建议**，不是 MManiST 或 DeepSpatial 原论文已有的训练损失。
- 极低丰度细胞可能处在合法的低密度区域；密度损失会误删稀有状态。需比较基于局部近邻的温和约束、类型条件校准与无正则化。
- 类型标签在生成期间可能未知；如使用预测类型概率，应做软条件并检查预测误差传播。**不能用隐藏真实切片标签辅助生成**。
- 同步测试“只修改 UOT”、“只加生成端约束”、“两者都加”，避免无法归因。

## 8. 实验推进顺序与阶段成果

| 顺序 | 阶段 | 关键动作 | 最终可交付成果 | 下一步门槛 |
|---|---|---|---|---|
| P0 | 数据与 baseline | 数据审计、固定 split、复现 DeepSpatial 和 MManiST | 数据审计表、原始模型重建结果、环境锁定 | 可复现且无泄露 |
| P1 | 表示检验 | PCA/AE、欧氏 GNN、双曲 GNN、联合嵌入公平比较 | 稀有类型判别/邻域/检索表、嵌入图、稳定性表 | 联合几何有独立且稳定增益 |
| P2 | UOT 消融 | 只替换表达代价，诊断稀有类型传输质量 | UOT 耦合质量表、错误配对图、质量流失报告 | 配对改善且未丢弃稀有质量 |
| P3 | 真实隐藏切片 | D0–D3 同主干重建，比较数量/位置/表达 | 主实验表、每类结果、置信区间与可视化 | 稀有恢复有效且整体不退化 |
| P4（可选） | 生成端正则 | 类型条件流形约束与独立消融 | 增量提升报告或否定结果 | 仅在收益大于复杂度时保留 |

### 建议的最小可行版本（MVP）

**只实现以下六件事：**

- [ ] 使用一组可靠标注的多切片 MERFISH 数据，选一个真实中间切片作为隐藏真值。
- [ ] 复现不改动的 DeepSpatial baseline，并保存原始 UOT 耦合。
- [ ] 训练同容量欧氏 GNN、Poincaré GNN 和两者简单融合的表示编码器。
- [ ] 验证稀有类型跨切片检索和同类 UOT 传输质量是否改善。
- [ ] 仅替换 UOT 表达代价，在原始 GiT 中重新训练并生成隐藏切片。
- [ ] 对比稀有细胞数量 RAE、位置 Wasserstein、marker signature 与整体 guardrails。

这 6 件事完成后，就可以初步判断是否值得发展为论文主线；**暂时不必加 Pareto 优化、Lorentz 第三分支或额外生成损失**。

## 9. 常见失败原因与决策树

| 观察到的现象 | 可能原因 | 下一步动作 |
|---|---|---|
| H1 不成立：双曲表示未改善稀有类判别 | 稀有细胞未呈层级几何；数据量小；超参数不稳 | 不进入双曲 UOT；尝试更稳健的欧氏编码/稀有类均衡 |
| H1 成立但 H2 不成立 | 跨切片表达检索与 UOT 的空间/类型代价冲突，或距离量纲不一致 | 检查代价分位数、权重及稀有类 UOT 未匹配质量 |
| H2 成立但 H3 不成立 | 更好的耦合被 GiT 训练或生成密度机制抵消 | 检查生成细胞总数、类型预测、空间速度和表达漂移 |
| H3 只改善表达，不改善位置 | 空间流/组织几何不足，或稀有类空间热点稀疏 | 单独研究类型条件空间分布，不再给表达嵌入加复杂度 |
| 结果只在一个稀有类型上显著 | 类型特异性强，可能过拟合 | 公开列出适用范围，在其他组织/样本验证 |
| 整体准确率提升但稀有类变差 | 类别不均衡被隐藏在宏观指标中 | 将稀有类型三项主要终点作为模型选择限制 |
| 双曲分支耗时和数值不稳定 | 曲率/边界/学习率不合适 | 固定曲率、限制范数、换稳定实现；必要时停止 |

**允许结论为否定：** 若不支持 H1–H3，报告“多流形表示未改善该数据上的稀有细胞三维恢复”，这仍然能排除无效研发路径。

## 10. 写论文时可能对应的科学贡献（目前均为待验证）

1. **科学发现层面**：识别低丰度细胞三维重建失败究竟发生在跨切片匹配阶段，还是生成阶段。
2. **方法层面**：提出条件化的欧氏–双曲混合表达成本，并将其接入 UOT，而非整个重写生成模型。
3. **评估层面**：建立同时覆盖稀有细胞数量、空间位置与表达程序的隐藏切片验证体系。
4. **理论边界**：实验说明负曲率潜在几何何时有帮助、何时不如更简单的欧氏嵌入。

不要在实验结果出现前写成“证明双曲流形更适合稀有细胞”或“显著提高低丰度细胞恢复”。
