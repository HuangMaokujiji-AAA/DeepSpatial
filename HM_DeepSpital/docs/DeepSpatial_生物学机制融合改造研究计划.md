# DeepSpatial 生物学机制融合改造研究计划

> **版本**：v1.0｜2026-10-26
> **定位**：以 DeepSpatial 为基线，围绕一个可证伪的生物学假设设计最小而深入的机制融合实验。
> **原则**：先证实机制信息具有额外价值，再修改生成模型；不以叠加网络模块或单纯提升全局指标作为主要研究贡献。

---

## 0. 一页研究摘要

### 拟定课题名称

**中文**：基于细胞生态位—分子程序关联约束的三维空间转录组重建方法研究
**英文**：*Niche–Gene Program Consistency-Guided Reconstruction of 3D Spatial Transcriptomics*

这是**暂定方法学题目**，不暗示已经证明因果性的细胞通信机制。若实验只能证明普通邻域信息有用，而不能证明功能性生态位先验的独立作用，应进一步收窄题目。

### 核心科学问题

> 在已知细胞类型、组织区域、空间坐标和可用观测切片的条件下，**细胞生态位与分子程序的关联**是否仍然为未观测三维空间的表达/细胞状态提供可泛化的附加信息？将这种信息引入 DeepSpatial，能否提升真实三维组织中的重建保真度？

### 待检验假设

- **H1（统计增益）**：控制细胞身份、解剖区域和空间信息后，真实邻域特征仍能提升预设分子程序的独立样本预测能力。
- **H2（机制内容增益）**：正确的生态位—程序关系对三维重建的帮助，大于随机关系和等强度的普通空间平滑。
- **H3（重建增益）**：融合上述关系后，隐藏真实三维数据上的分子程序空间分布、细胞类型组成及低丰度细胞空间恢复优于原 DeepSpatial，且不牺牲整体重建质量。
- **H4（稳健性）**：在先验不可靠或组织分布发生变化时，机制约束不应产生更自信、更严重的错误。

**零假设**：上述增益不能超过更大模型容量、更多训练数据、空间自相关或错误先验所产生的效果。

### 研究边界

- **核心任务**：真实/模拟稀疏观测条件下的三维组织重建。
- **机制含义**：已知知识支持、可在独立数据上检验的**生态位—分子程序统计依赖**；不是直接声称发现因果信号通路。
- **关注但不绑架课题**：低丰度细胞可作为高敏感度验证子任务，不把全部方法创新限制在稀有细胞上。
- **不刻意围绕**：大间距或不等距采样；可作为后续稳健性实验，不作为当前科学问题前提。

## 1. 为什么选择 DeepSpatial：原模型与明确缺口

### 1.1 原论文的主要流程

观测细胞状态：

\[
s_i=(\mathbf x_i,\mathbf g_i,c_i),\qquad \mathbf x_i\in\mathbb R^2
\]

原方法总体流程：

```text
实测二维切片：XY、基因表达、细胞类型、真实 z 位置
        ↓
空间配准与全局归一化
        ↓
UOT：空间 + 表达 + 细胞类型代价
        ↓
UOT 配对 → Flow Matching 训练样本
        ↓
GiT：单细胞的空间 Token + 基因 Token + 类别/深度条件
        ↓
位置/表达/类别联合速度场
        ↓
双向 ODE 采样 → 虚拟细胞 → 数量与表达后处理
        ↓
连续三维细胞点集（XYZ、表达、类型）
```

原论文 UOT 代价的主要形式：

\[
C_{ij}=\alpha D_{ij}^{spatial}+(1-\alpha)D_{ij}^{gene}
+\lambda_{cell}\,\mathbf1[c_i\neq c_j].
\]

原论文及实现的核心思想是学习细胞状态运输；**尚未显式建模某个细胞的邻近细胞构成、空间生态位和功能程序如何共同约束其表达**。但不能据此声称模型完全无法间接学习邻域统计信息；这必须通过对照实验来证明。

### 1.2 已审查的实现细节（需冻结代码版本复核）


| 实现位置                               | 已观察到的公开代码行为                                                      | 对研究的影响 / 必须检查的事项                                                      |
| ---------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |

### 1.3 需要严格区分的三种改进

1. **实现修复**：纠正文档/代码差异、修复后处理偏差。它是严谨 Baseline 审计，不能自动算新方法创新。
2. **普适算法正则化**：平滑、增加容量、增加类别 Loss。可能有效，但未证明机制知识起作用。
3. **机制内容有效的重建改进**：真实生态位—程序关系比随机关系、纯空间关系更有助于独立真实数据的恢复。这才是研究目标。

## 3. 最重要的前置实验：先证明生态位信息有增量价值

### 3.1 不改 DeepSpatial，先回答生物学问题

选定一种或少量预注册的细胞类型和功能基因程序，分别构造：

- `C_i`：细胞类型；
- `R_i`：组织区域、可用空间位置及必要的技术协变量；
- `N_i`：**不包含该细胞自身**的邻域细胞类型组成、距离加权组成、可用的邻居分子程序；
- `P_i`：由**预先确定且训练外证据支持**的基因集合计算的目标分子程序活性。

比较三种预测器（保持容量与训练预算可比）：

\[
\begin{aligned}
\text{M0}:\quad &\hat P_i=f_0(C_i,R_i),\\
\text{M1}:\quad &\hat P_i=f_1(C_i,R_i,N_i),\\
\text{M2}:\quad &\hat P_i=f_2(C_i,R_i,\widetilde N_i),
\end{aligned}
\]

其中 `Ñ_i` 是在合理分层内随机打乱的邻域特征，尽可能保留区域、细胞丰度及空间自相关的背景性质。

**观察重点**：独立样本上的 `M1` 是否明显优于 `M0`，且 `M2` 无法复制这一增益。

建议先报告留出样本预测损失差：

\[
\Delta_{niche}=\mathcal R(M0)-\mathcal R(M1).
\]

这里的 `R` 是在预先固定测试集上的风险（如 MAE/MSE），而不是训练损失。

### 3.2 必须排除的混杂与泄漏

- **自身表达泄漏**：邻域聚合不能包含目标细胞自身；预测目标的 marker 不得借同一细胞的输入再次进入预测器。
- **空间自相关**：随机划分单个细胞通常过于乐观，应采用空间块与生物样本级分割。
- **细胞类型泄漏**：若类型标签使用了目标 marker 基因推断，应进行去目标基因或独立标注的敏感性分析。
- **组织区域混杂**：邻域仅仅告诉模型“这在海马还是纹状体”，不等于存在新的生态位信息。
- **外部知识泄漏**：不能拿隐藏测试组织计算真实基因程序/邻域，再作为推断条件输入。

### 3.3 GO / NO-GO 门槛

- **GO**：真实邻域的增量效果在多个独立验证单元中方向一致，置信区间和置换对照支持改善，并且不只依赖某一强 marker 或某一组织区域。
- **NO-GO**：真实邻域与随机邻域效果近似、收益完全由组织区域解释，或只在单细胞随机切分而非独立样本上有效。此时不应立刻大改生成架构。
- **边界情形**：只有特定细胞类型/通路有效，可以把研究进一步收窄为该明确生物场景，而不是扩展成通用机制模型。

## 4. 最小方法改造：保留 DeepSpatial 主干，只验证一个机制

### 4.1 推荐方向：Niche–Program Consistency（NPC）

保留：

- DeepSpatial 的几何配准与 UOT；
- GiT 主体结构；
- 原始位置/基因/类别速度场；
- ODE 积分与主推理接口。

新增：

1. **可复用的 Niche Featurizer**：根据细胞三维邻域计算类型组成与少量预先指定的功能特征。
2. **冻结的 Niche→Program 预测器** `f_φ`：在训练集真实观测上独立训练，提供可检验的关联先验。
3. **一个轻量约束或条件接口**：先仅实现一种，不同时引入复杂 GNN、密度模型、GRN 和全新扩散模型。

### 4.2 推荐两个循序实验版本

#### V1：生态位条件 GiT（实现风险较低）

为训练配对两端的细胞分别计算仅基于可用观测的邻域表示 `h_niche`，由配对端点生成流路径时的条件特征，并接入 GiT 已有的条件调制：

\[
w_t'=w_t+\lambda_n W_n h_t^{niche}.
\]

初始版本可将端点邻域向量沿配对路径插值，但**这只是一个算法近似**，不能把插值出的生态位当成真实三维邻域。推理时仅可使用观测端点的信息及模型自主生成的信息。

**V1 的要点不是“加一个 Encoder”**：必须设置相同容量的随机邻域、打乱邻域及纯空间条件对照，证明改善源自正确的邻域结构。

#### V2：生成后三维生态位一致性引导（更接近科学假设）

先让原 DeepSpatial 生成初始虚拟细胞，再在**生成结果**上计算三维邻域 `N̂_i`，用预训练冻结的关联模型约束生成程序 `P̂_i`：

\[
\mathcal L_{NPC}=\frac1{|\mathcal I|}\sum_{i\in\mathcal I}
\omega_i\,\ell\Big(\hat P_i, f_\phi(\hat N_i,\hat C_i,\hat R_i)\Big).
\]

- `P̂_i`：从生成的基因表达计算的目标分子程序活性；
- `f_φ`：冻结、在**训练真实数据**上拟合的 Niche→Program 预测器；
- `ω_i`：先验适用性/置信度权重，需要独立校准，不能任意调低难样本权重来取巧；
- `ℓ`：例如稳健回归损失。

联合目标：

\[
\mathcal L_{total}=\mathcal L_{FM}+\lambda_{NPC}\mathcal L_{NPC}.
\]

**实现警告**：当前 DeepSpatial 的常规训练批次主要是 UOT 采样的单细胞轨迹对，并没有现成的真实三维邻域。故 `L_NPC` 不能直接插到 `_shared_step()` 就宣称成立。需额外设计可微的生成邻域估计、局部生成批次或生成后迭代修正；候选邻域可先用固定半径 + 软核近似，避免离散 KNN 切换导致梯度不可用。若开销过大，应先做冻结模型的后验细化试验，明确它与端到端训练的差异。

### 4.3 不推荐在第一版同步引入的改动

- 重新设计完整 UOT 代价；
- 引入复杂配体—受体因果网络；
- 同时预测组织结构、类型条件密度和所有基因程序；
- 用未知 GT 邻域作为推理输入；
- 因为稀有细胞结果不好就先人为过采样，再宣称机制有效。

这些可以是后续消融确认问题后的扩展，但不是第一轮的必要条件。

## 5. 独立验证：除了模型本身，还有什么能证明结果正确？

### 5.1 最小对照矩阵


| 组别 | 描述                                           | 目的                           |
| ------ | ------------------------------------------------ | -------------------------------- |
| A0   | 原始 DeepSpatial                               | 冻结基线表现                   |
| A1   | DeepSpatial + 普通空间平滑/等成本正则化        | 排除一般正则化收益             |
| A2   | DeepSpatial + 随机打乱的 Niche–Program 关系   | 排除“随便添加一个先验就有效” |
| A3   | DeepSpatial + 真实 Niche–Program 约束         | 验证生物关系的独立效果         |
| A4   | DeepSpatial + 等参数量但不含真实先验的条件网络 | 排除网络容量和额外计算量的贡献 |

最关键的是 **A3 vs A2/A4**，而不是只看 A3 vs A0。

### 5.2 数据切分协议

**第一阶段内部技术验证（少量切片）**：例如有按真实 z 排列的 5 张 MERFISH 切片，可用第 1/3/5 张为模型观测数据，把第 2/4 张完整隐藏用于评估；模型在新相邻的已观测切片对之间重建，保留真实物理 z。此前已用到隐藏切片进行配准、特征筛选、归一化参数或先验学习的流程必须修正。

**第二阶段真正三维 GT**：从完整直接三维分子测量数据中提取预设观测薄层，在其余未观测体积评估三维细胞位置与程序；完整测量仅交由独立评估脚本读取。

**第三阶段外部泛化**：在不同组织块/动物/供体（如可获得）上测试；若只能同一组织内部划分，结论限定为内部泛化，不能声称跨生物样本泛化。

### 5.3 评价指标（和《DeepSpatial_稀有细胞三维重建评价指标.md》配套）


| 维度                 | 指标                           | 主要公式 / 操作                                             | 方向             | 用途与注意事项                                              |
| ---------------------- | -------------------------------- | ------------------------------------------------------------- | ------------------ | ------------------------------------------------------------- |
| **主终点：分子程序** | Held-out Program MAE/MSE       | `mean(                                                      | P̂_v-P_v        | )`/`mean((P̂_v-P_v)^2)`，在固定三维网格/切片内比较         |
| **主终点：空间出现** | Rare-cell Occupancy AP         | 对固定三维网格，`y_v=1[N_{v,c}>0]`，以预测密度作分数计算 AP | ↑               | 不强行要求真实细胞与虚拟细胞逐个对应；报告阳性网格占比      |
| 数量                 | Rare-cell Count Relative Error | `                                                           | N̂_c−N_c       | /N_c` (`N_c>0`)                                             |
| 占比                 | Proportion Absolute Error      | `                                                           | N̂_c/N̂−N_c/N | `                                                           |
| 位置                 | Spatial F1@r                   | 一对一距离阈值匹配后 `2M/(N_c+N̂_c)`                       | ↑               | 合成细胞非真实细胞的同一实体；结果对 r 敏感，应预设多个尺度 |
| 分布                 | Spatial Wasserstein / EMD      | `W₁(μ_c,μ̂_c)`                                          | ↓               | 默认归一化后的空间分布，不单独表征绝对数量                  |
| 分子身份             | Marker MMD / SCC               | 比较预设 marker 表达分布；有对齐位置才用表达相关            | MMD↓ / SCC↑    | 不能仅依赖生成模型自身输出的 `cell_class` 标签              |
| 生态位               | Neighborhood Enrichment Error  | 真实与预测 3D 邻域的共定位/富集统计差                       | ↓               | 与机制内容直接相关；需要正确三维图与稀有群体数目支持        |
| 聚集性               | 3D Ripley's K/L Error          | 真值与预测点过程多尺度曲线差                                | ↓               | 需使用 **3D** 公式和边界校正，少样本不稳                    |
| 可信度               | Error–Uncertainty Calibration | 预测不确定性与真实误差/覆盖率比较                           | 越校准越好       | 未显式建模不确定性时暂不作为主要创新承诺                    |

> 单细胞三维生成并非细胞轨迹跟踪；**不能用 Spatial F1@r 声称恢复了同一个真实细胞**。对生成任务，区域 AP、点模式统计及程序分布误差往往更符合任务语义。

### 5.4 统计证据与独立性

- 基本重复单元优先使用**供体/动物/独立组织块**，而不是把同一组织中的百万个细胞当作百万次独立实验。
- 逐细胞类型、逐样本报告指标，保留低丰度类型的最差表现；统计总体建议宏平均。
- 在预先指定的主要终点上报告效果量和 95% 置信区间；可以使用样本级 bootstrap；小样本下说明区间不稳定。
- 预先确定多个比较的主检验和校正方法；不同训练种子只反映训练稳定性。
- 检查机制知识的**错误先验/异组织先验**影响；不以未知测试集来自动选择最有利的约束权重。
- 在有实验合作条件时，用独立原位 RNA/蛋白检测做特定分子程序验证；若要声称因果细胞通信，还需扰动实验。

### 6.2 计算与训练上的现实约束

- 原 UOT 需要跨切片细胞配对，代价矩阵可能近似按 `N0 × N1` 增长；先从小体积、少类别、可重复切片开始。
- 24 GB 显存上优先使用显式 `batch_size/chunk_size`、训练时基因数受控、局部邻域缓存与分块评价；**不保证所有原始大规模数据可直接跑通**。
- 大规模训练前先在一个极小数据上做单 batch 过拟合检查、loss 量纲检查、抽样和推理一致性检查。
- V2 的邻域一致性若对全部生成细胞构图会很昂贵，优先局部抽样，并量化额外计算成本，和原基线公平比较。

## 7. 给 Codex / 研究智能体的任务边界

推荐按以下顺序逐项提交 PR/实验结果，**不要允许智能体无条件迭代直到“刷出更好指标”**：

1. **仅阅读和审计**：列出仓库真实调用链，明确 UOT 输入、GiT 条件、训练损失、ODE 采样、稀疏化与评估输出的代码位置；不修改方法。
2. **建立冻结 Baseline**：新增可重复运行脚本、数据划分、指标与日志；在参照版本上确认原结果。
3. **独立生物学假设实验**：实现邻域构造、预注册程序提取、真实/随机邻域预测增益；输出逐样本统计。
4. **只实现 V1**：通过开关加生态位条件；使用原损失和推理主干，控制参数量；输出消融和失败案例。
5. **满足门槛才实施 V2**：增加机制一致性引导，独立显示是否超越 V1、A1/A2/A4；不允许使用隐藏 GT 调参。
6. **独立评估复核**：验证文件来源、实际使用过的细胞 ID、划分泄漏、空间尺度、类别标签、随机种子、训练参数与结果。

**智能体必须给出**：改动文件清单、实验 config、代码版本、训练日志、指标 CSV、失败案例、改动与效果的因果归因尝试；**不得自行修改测试集、删掉不利类别或替换主指标**。

## 8. 最重要的判断标准：什么结果才算研究成功？

**可接受的深入成果**：

- 证明“细胞生态位—分子程序依赖”在独立真实数据中有额外的预测信息；
- 证明这一依赖对**隐藏的三维分子状态**有实质帮助，且优于随机机制、纯空间正则和容量匹配对照；
- 能解释增益出现在何类细胞/组织结构中、何时失效；
- 基线性能保留在合理水平，改善不以大量虚假稀有细胞或过度平滑为代价；
- 代码、原始数据来源、评估过程和统计证据可让第三方复查。

**不应直接宣称成功的情况**：

- 仅全局 PCC/MSE 改善；
- 增加网络参数后提升，但随机邻域也一样提升；
- 仅在训练/验证随机抽出的细胞上有效，在独立组织块上无效；
- 主要收益来自修复 DeepSpatial 后处理 Bug，而非机制内容；
- 模型内部输出的类型标签与内部生态位评分更一致，但缺少独立真实测量证据；
- 使用配体—受体数据库就称自己验证了因果细胞通信。

### 核心结论

> **先问“真实生态位知识是否带来超越细胞类型和空间信息的可泛化增益”，再问“如何把它融入 DeepSpatial”。**
>
> 最小研究单元是一个可被否定的生物学假设、一处可控的方法修改、一组独立原始真值，以及能够排除容量、平滑、数据泄漏和随机先验影响的对照实验。研究的价值取决于证据深度，而不是模型模块数量。
