# DeepSpatial：三个关键定义与文献依据

检索日期：2026-10-26。对应《DeepSpatial_生物学机制融合改造研究计划.md》v1.0。

本文补充可观测邻域、V1 轨迹条件和 V2 程序波动的定义。公式中标为“建议”的部分是针对 DeepSpatial 的适配设计；引用文献支持其组成思想，不代表文献已经验证了这一组合的效果。本文未开展模型训练。

## 推荐采用的首版定义

| 问题 | 首版定义 | 对应的方法含义 |
|---|---|---|
| 稀疏观测下的邻域 | 源细胞所在实测切片内，排除自身、按物理距离加权的细胞类型组成，并附带观测支持信息 | 为生成提供可计算的局部组织上下文 |
| V1 轨迹条件 | 每条轨迹携带其源细胞的邻域表征，整个 ODE 过程中保持该表征固定 | 条件来自实测源细胞；正反向分别使用各自的源切片 |
| V2 允许的程序波动 | 相同细胞类型、邻域和可用组织条件下，真实数据估计的程序预测区间 | 区间内不施加 NPC 收缩，超出区间才产生软惩罚 |

## 1. 稀疏观测下，实际可获得的邻域是什么？

### 1.1 文献依据

- **BANKSY，Nature Genetics，2024**：将细胞自身表达与距离核聚合的邻域表达分开表示；官方实现支持 kNN 和半径邻域等核。[论文](https://www.nature.com/articles/s41588-024-01664-3)，[官方核函数说明](https://prabhakarlab.github.io/Banksy/reference/computeBanksy.html)。它支持“邻域特征可作为单独上下文”的做法，没有给出稀疏切片到完整三维生态位的无偏恢复保证。
- **NCEM，Nature Biotechnology，2023，在线发表于 2022**：利用空间半径定义邻接关系，根据细胞类型、邻域类型信息和样本条件预测表达；并讨论了细胞内在变化与生态位效应的共同建模。[论文](https://www.nature.com/articles/s41587-022-01467-z)。借用的是物理尺度邻域与类型条件建模，不是将其某个数据集的最优半径直接移植过来。
- **Niche-DE，Genome Biology，2024**：用物理距离核加权的各类型细胞数量定义 effective niche，并考察多个带宽。[论文 Results：Single-cell niche-differential gene expression model，及 Methods](https://link.springer.com/article/10.1186/s13059-023-03159-6)。下述归一化类型组成、排除自身和支持信息，是对本任务的适配。

### 1.2 建议的可执行定义

令实测观测集合为

\[
\mathcal O=\{(\mathbf u_i,z_{s_i},c_i,\mathbf g_i,s_i)\},
\]

其中 \(\mathbf u_i\) 是以微米表示的切片内坐标，\(s_i\) 为切片 ID。首版定义

\[
\mathcal N_i^{obs}(r)=
\{j\in\mathcal O:j\ne i,\ s_j=s_i,
\|\mathbf u_j-\mathbf u_i\|_2\le r\}.
\]

即：在该源细胞所属实测切片内寻找物理距离不超过 \(r\) 的其他细胞。对候选邻居使用

\[
w_{ij}=\exp\left[-\frac{\|\mathbf u_j-\mathbf u_i\|_2^2}{2\sigma^2}\right],
\qquad m_i=\sum_{j\in\mathcal N_i^{obs}}w_{ij}.
\]

当 \(m_i>0\) 时，第 \(a\) 类的邻域组成是

\[
n_{ia}^{obs}=\frac{\sum_{j\in\mathcal N_i^{obs}}w_{ij}\mathbf1[c_j=a]}{m_i}.
\]

首版表征建议为

\[
h_i^{obs}=\operatorname{concat}
\left(\mathbf n_i^{obs},\log(1+m_i),n_i^{eff},b_i\right),
\qquad n_i^{eff}=\frac{m_i^2}{\sum_j w_{ij}^2},
\]

其中 \(b_i\) 为邻域缺失标志。无邻居时，将组成与有效邻居数置零，并令缺失标志为 1。\(m_i\) 表示观测到的加权细胞量；它没有经过观测面积/体积校正，不能直接称作真实三维细胞密度。若可取得组织掩码，再加入邻域圆盘落在有效组织内的面积比例，以区分组织边缘截断。

第一版仅使用类型组成，避免同时引入邻居表达处理和程序评分的额外选择。后续若加入邻居分子程序，仍从 \(\mathcal O\) 聚合，并排除源细胞自身。

### 1.3 与完整三维生态位的关系

上面的 \(h_i^{obs}\) 定义的是“实测切片内的局部上下文”。对于完整测量或生成体积中的细胞，三维生态位另记为

\[
\mathcal N_i^{3D}(r)=\{j\ne i:\|\mathbf p_j-\mathbf p_i\|_2\le r\},
\quad \mathbf p_i=(x_i,y_i,z_i).
\]

实测切片内上下文与三维生态位使用不同记号，训练先验时也保持其特征含义一致。切片间距大于邻域半径时，跨切片的近邻无法由实测数据直接获得；固定 kNN 则可能跨越很远的距离。首版用物理半径限定局部范围，kNN 可用于限制候选数量，但不强行凑满邻居。

\(r\)、\(\sigma\) 在训练/验证集上选择并固定。文献支持尺度选择的重要性，没有提供对所有组织和技术通用的微米数。P1 中的完整三维邻域实验回答生物关联是否存在；实际生成收益仍需用上述可观测上下文检验。

## 2. V1：每条推理轨迹如何取得条件？

### 2.1 文献与本地实现依据

条件生成可以在向量场中显式加入可提供的条件变量。Flow Matching 的一般构造见 [Lipman 等，ICLR 2023](https://openreview.net/forum?id=PqvMRDCJT9t)；进一步参考 [Flow Matching Guide and Code，2024，预印本](https://arxiv.org/abs/2412.06264)。官方实现的 [train_loop.py](https://github.com/facebookresearch/flow_matching/blob/main/examples/image/training/train_loop.py) 在训练时传入标签条件，[eval_loop.py](https://github.com/facebookresearch/flow_matching/blob/main/examples/image/training/eval_loop.py) 在 ODE 求解时继续传入该条件。

这里应区分两件事：用于构造 FM 监督目标的端点配对，可以只在训练时使用；额外传入神经网络的生态位条件，则必须定义推理时的计算方式。

本地 `deepspatial/core.py` 的 `_generate_and_prune_optimized()` 从某一端抽取源细胞，计算轨迹，再混合两个方向的结果。每条轨迹有源细胞索引，但没有预先指定另一端的 UOT 目标细胞。源条件方案正好利用了现有索引。

### 2.2 推荐：源邻域固定条件

对从源细胞 \(i\) 出发的轨迹，定义

\[
h_{traj}=h_i^{obs},\qquad h_{traj}(t)\equiv h_{traj}.
\]

令 \(s_t=(\mathbf x_t,\mathbf g_t,\mathbf c_t)\) 为联合状态，模型为

\[
\frac{d s_t}{dt}=v_\theta(s_t,t,z_t,\Delta z;h_{traj}),
\]

并在原 GiT 条件向量上加入

\[
\operatorname{cond}'_t=\operatorname{cond}_t+W_n h_{traj}.
\]

\(t\)、\(z_t\) 及细胞状态继续变化；固定的是从实测源细胞取得的上下文。此方案是本研究的首版设计建议，文献没有证明它对 DeepSpatial 必然有效。

### 2.3 训练与推理如何保持一致

| 情形 | 初始状态 | 新增条件 | 监督/演化规则 |
|---|---|---|---|
| 正向训练 \(i\to j\) | UOT 配对源 \(s_i\) | \(h_i^{obs}\) | 原配对路径及速度目标 |
| 反向训练 \(j\to i\) | 配对另一端 \(s_j\) | \(h_j^{obs}\) | 交换端点，重算 \(\Delta z\) 与速度目标 |
| 正向推理 | 已抽取的下侧源细胞 | 同一源索引查询 \(h_i^{obs}\) | 整条 ODE 固定传入 |
| 反向推理 | 已抽取的上侧源细胞 | 同一源索引查询 \(h_j^{obs}\) | 整条 ODE 固定传入 |

方向信息可通过已有的有符号 \(\Delta z\) 表示。建议显式覆盖两个方向；若新增反向训练增强，则相同训练处理也用于不含生态位条件的对照，以辨认两种改动各自的作用。

因此，训练时不再把 \((1-t)h_i+t h_j\) 作为首版网络输入。UOT 端点仍用于建立 FM 监督，生态位条件改为源端观测。实现应让 `dataset.py`、`module.py` 的训练和采样接口、GiT 及 `core.py` 中的源细胞索引一致传递 `niche_cond`。

源条件携带的是轨迹起点的上下文，不能解释成每个中间位置已经获得真实三维邻域。若后续需要位置相关条件，可在当前生成位置查询仅由观测切片构成的条件场；那是另一种需要单独验证的版本。

### 2.4 直接相关的邻域增强生成工作

[STITCH，bioRxiv，2026，预印本](https://www.biorxiv.org/content/10.64898/2026.06.03.729557v1.full) 的第 4.4.2 节提出 STITCH-n：速度场同时使用动态生成邻居与固定真实上下文，并采用统一流时间。它表明邻域与流可以显式耦合，也表明这类方案涉及联合演化。首版固定源条件保留逐细胞轨迹接口；本课题的进一步贡献应落在可检验的生态位—程序关系及其重建作用上。不能仅凭增加邻域模块主张这一机制首次出现。

## 3. V2：允许多大的程序波动？

### 3.1 文献依据与目标量

[NCEM](https://www.nature.com/articles/s41587-022-01467-z) 的概率模型区分了预测表达与残余变化；[NicheCompass，Nature Genetics，2025](https://www.nature.com/articles/s41588-025-02120-6) 使用变分潜变量和计数分布重建自身及邻域表达。两者都支持“邻域相关性不等于唯一确定状态”的理解。

对本计划已经计算出的连续程序评分，更直接的工具是 [Conformalized Quantile Regression，NeurIPS 2019](https://papers.neurips.cc/paper_files/paper/2019/hash/5103c3584b063c431bd1268e9b5e76fb-Abstract.html)，它估计随条件变化的预测区间。基因原始计数可以使用负二项模型；归一化后的程序分数应按其自身分布建模。

令第 \(k\) 个程序分数为 \(P_{ik}=S_k(\mathbf g_i)\)。基因集合、评分函数和归一化参数从训练资料确定，在真实数据与生成表达上保持相同。令

\[
Z_i=(\mathbf n_i^{3D},C_i,R_i),
\]

其中 \(R_i\) 仅包含推理时可得的组织/空间条件。首版三维先验使用类型组成，位置和类型固定后，该生态位也固定。

### 3.2 推荐：条件预测区间

为程序 \(k\) 学习两个条件分位数：

\[
L_{ik}=\widehat Q_{\alpha/2}(P_k\mid Z_i),\qquad
U_{ik}=\widehat Q_{1-\alpha/2}(P_k\mid Z_i).
\]

例如预先取 \(\alpha=0.10\)，对应名义 90% 预测区间。90% 是初始设计选择，非生物学常数；也可预先指定 95% 为敏感性设置。每个细胞类型、生态位与程序的区间宽度由数据估计，不能统一写成“均值上下浮动 10%”。

该区间描述新细胞程序评分的预测范围。均值置信区间回答平均值估计有多精确，不能替代个体状态的允许范围。程序评分的观测波动同时包含生物差异、测量噪声与未解释变异；没有技术重复或测量模型时，应称为“条件预测容许范围”，不宣称已分离纯生物学波动。

### 3.3 校准及适用范围

用先验训练集拟合分位数；以独立校准样本检查覆盖率和区间宽度，必要时校准边界；最终测试集不参与这些选择。基础 CQR 的覆盖保证需要校准与新样本满足可交换性。

同一组织中的细胞具有空间相关，跨组织又存在分层结构。[Distribution-free inference with hierarchical data，arXiv:2306.06342v2，2023](https://arxiv.org/html/2306.06342v2) 说明普通逐观测校准不能直接继承分层数据的保证。首版按独立组织/动物保留校准单元，报告逐样本、逐类型的经验覆盖；仅做分组划分本身不构成覆盖定理。若采用分层 conformal，还需检查它的组间和组内可交换性要求。

即使真实留出数据上的覆盖良好，也不能据此承诺优化后生成细胞满足相同覆盖率，更不能直接承诺任意异组织先验下的 H4 稳健性。

三维先验应在训练用真实三维观测上，按相同的三维邻域定义拟合和校准。若当前只有稀疏二维切片，可先研究二维上下文版本；二维邻域训练出的预测器，不能直接把三维邻域作为同分布输入。

### 3.4 用区间约束替换点回归约束

令 \([a]_+=\max(a,0)\)，\(s_k>0\) 为训练数据确定的固定程序尺度，例如带下限的 IQR。建议采用

\[
\mathcal L_{band}=\frac1{|\mathcal I|K}
\sum_{i,k}\frac{
[L_{ik}-\hat P_{ik}]_+^2+
[\hat P_{ik}-U_{ik}]_+^2}{s_k^2}.
\]

区间内损失为零，不向条件均值拉动；区间外按偏离程度软惩罚。分位数预测器在生成优化之前冻结，生成器不能通过调宽区间来降低损失。

这给出了可操作的“允许波动”定义，但不会单独保证多峰结构或少数激活状态完整保留。基础生成目标/偏离约束负责保留原有变化，还需观察真实与生成程序分布的尾部和状态比例。

### 3.5 最小的 V2 后验细化版本

首轮固定生成位置、细胞类型和观测细胞，使用类型组成构造固定三维邻域，仅调整虚拟细胞表达。以基础模型输出 \(\mathbf g_i^{base}\) 为参照，优化

\[
\mathcal L_{refine}=\lambda_{band}\mathcal L_{band}
+\beta\,\frac1{|\mathcal I|}\sum_i
\|D_g^{-1}(\hat{\mathbf g}_i-\mathbf g_i^{base})\|_2^2,
\]

其中 \(D_g\) 是训练数据确定、具有正下限的基因尺度矩阵。表达修改保持原预处理的数据域约束。该目标是“冻结基础模型后的表达细化”；端到端版本才另外定义如何结合 FM 训练目标与生成邻域。

固定位置与类型后，类型组成无需通过构图反向传播，第一轮可以直接检验程序约束的作用。此版本直接追求表达/程序保真度，细胞位置和数量不会被它主动修正。

## 4. 可直接并入原计划的三段定义

**可观测邻域。** 本研究将稀疏观测下的生态位输入定义为源细胞所在实测切片内、排除自身并按物理距离核加权的细胞类型组成，同时记录加权观测细胞量、有效邻居数与缺失标志。该表征反映可观测的局部组织上下文；完整三维邻域在独立三维先验与生成体积中另行构建。

**V1 轨迹条件。** 每条生成轨迹使用其源细胞预计算的邻域表征，并在 ODE 积分期间保持该表征固定。训练与推理采用同一取条件规则；正反向轨迹分别使用各自源切片的细胞索引和邻域表征。UOT 端点配对用于 FM 监督，额外生态位条件由实际可观测的源细胞提供。

**V2 程序容许波动。** 本研究在独立训练与校准数据中，估计给定细胞类型、生态位和可用组织条件下的程序活性预测区间，以此定义允许波动。NPC 仅对超出区间的生成程序施加软惩罚，区间内保留基础模型产生的状态差异。首版固定位置与类型进行表达细化，三维先验的训练与应用使用相同的邻域算子。
