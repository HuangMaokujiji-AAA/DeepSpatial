# 面向稀有细胞恢复的空间转录组学三维重建 —— DeepSpatial 改造方案

> 目标：在 DeepSpatial（流匹配 + 非平衡最优传输 + 联合状态生成）基础上，系统性提升低丰度（稀有）细胞的空间位置、数量、标记基因模式与局部生态位恢复能力。  
> 核心原则：不依赖全基因组 GRN（成像数据基因数有限，构建难度高、收益不确定），转而使用**已知 Marker + 局部生态位组成 + 类型感知机制**。

---

## 一、问题重定位与完整故事

### 1.1 核心问题
现有三维重建方法（包括 DeepSpatial）以全局分布拟合或按细胞平均损失为主，导致：
- 稀有细胞（可见切片中比例 <1%）运输质量低 → 进入训练轨迹机会少
- 损失权重低 → 局部状态难以被有效修正
- 最终空间位置、标记基因分布和邻域微环境信息丢失

### 1.2 升级后的故事主线
稀有细胞的恢复不仅是“生成对的数量和位置”，更是恢复其**特异的空间生态位**和**标记基因空间模式**。  
通过显式建模「类型感知的运输与抽样 + 双端生态位条件修正 + Marker 一致性约束」，在三维重建中保留对精细组织分区和局部微环境至关重要的低丰度群体，并支撑具体的生物学发现（如特定稀有神经元亚型的亚区富集、肿瘤侵袭前沿低丰度免疫亚群的空间分布）。

### 1.3 为什么不主打基因调控网络（GRN）
- 成像类空间转录组（MERFISH、STARmap、Xenium 等）通常仅测 100–500 个基因，面板高度选择，全基因组 GRN 推断不可靠。
- 构建成本高、噪声大，在当前主流三维重建数据设定下性价比低。
- 更优替代：已知 Marker（构建极简单、信号极强）、局部细胞类型组成（生态位）、类型层级/相似性。

## 二、重新设计的稀有细胞评价指标体系

必须同时满足「位置对、数量合理、身份对、局部环境对」，防止通过多生成稀有细胞刷高指标。

### 2.1 第一层：位置与数量保真

| 指标 | 计算方式 | 作用 |
|------|----------|------|
| Rare Spatial Recall @r | 真实稀有细胞周围 r μm 内是否存在同类型生成细胞（按稀有类型宏平均） | 基础覆盖 |
| Rare Precision @r | 生成的稀有细胞周围 r μm 内是否有真实同类型细胞 | 防止乱放 |
| One-to-one Matching Distance | 类型内匈牙利算法一对一匹配后的平均/中位欧氏距离 | 真正位置精度 |
| Count Relative Error | \|生成数 - 真实数\| / 真实数（稀有类型宏平均） | 数量不能随意膨胀 |

推荐同时报告 r = 50 μm 和 100 μm。

### 2.2 第二层：身份与表达保真

| 指标 | 计算方式 | 作用 |
|------|----------|------|
| Marker Gene Spatial Correlation | 稀有类型已知 marker 在真实 vs 生成空间分布上的 Spearman/Pearson 相关 | 核心生物学指标 |
| Type-conditioned Expression Similarity | 仅在同类型细胞内计算表达向量的余弦相似度或 MSE | 去除常见类型干扰 |
| Marker Enrichment Score | 生成稀有细胞中 marker 的平均表达富集程度 vs 真实 | 身份纯度 |

### 2.3 第三层：局部微环境与组织结构保真（区分度最高）

| 指标 | 计算方式 | 作用 |
|------|----------|------|
| Local Composition KL/JS | 真实稀有细胞邻域类型组成直方图 vs 生成稀有细胞邻域组成的 KL/JS 散度 | 生态位是否正确 |
| Niche Preference Score | 稀有细胞到其偏好邻居类型的平均距离或共现频率 | 微环境偏好是否保留 |
| Rare Density Spatial Correlation | 稀有细胞密度图与真实密度图的相关，或 Moran’s I 一致性 | 整体空间模式 |

### 2.4 推荐主指标组合（论文主表强制报告）
1. One-to-one Matching Distance（位置精度）
2. Rare Precision @50μm + Recall @50μm（平衡覆盖与准确性）
3. Marker Gene Spatial Correlation（生物学身份）
4. Local Composition KL（微环境）

全局 MSE / MAE / PCC 仅作为补充，证明未严重牺牲整体重建质量。

## 三、实验设计

### 3.1 数据建议
优先选择具备以下条件的数据：
- 有连续多切片或真实 3D 体积
- 有可靠的单细胞类型注释
- 存在文献验证的稀有亚型空间富集模式

推荐起点：
- MERFISH 小鼠下丘脑 / 脑区（稀有神经元亚型）
- Deep-STARmap 小鼠脑
- 肿瘤相关数据（低丰度免疫细胞在侵袭前沿）

### 3.2 核心实验设置

| 实验 | 目的 | 具体做法 |
|------|------|----------|
| Hold-out 切片重建 | 评价未观测深度恢复能力 | 隐藏中间切片，用两侧可见切片生成，与真实对比 |
| 稀有细胞专项评价 | 聚焦低丰度群体 | 仅对比例 <1% 的类型计算上述三层指标 |
| 消融实验 | 证明各模块贡献 | 去掉类型感知运输 / 去掉生态位条件 / 去掉 Marker 损失 |
| 生物学案例 | 连接发现 | 选择 1–2 个有文献支持的稀有亚型，展示空间富集恢复 |
| 跨样本/跨平台 | 泛化能力 | 在不同动物或不同技术数据上测试 |

### 3.3 对照方法（Baseline）
- DeepSpatial（直接上一代，必须对比）
- SpatialZ（分布插值强对照）
- STADiffuser（扩散范式）
- MIMYR（分阶段生成）
- STAGE（经典表达映射，作为参考）

### 3.4 结果叙事顺序（论文友好）
1. 稀有细胞位置与数量恢复（Matching Distance + Precision/Recall）
2. Marker 基因空间模式恢复（最重要生物学证据）
3. 局部生态位组成恢复
4. 消融实验
5. 具体生物学案例可视化 + 与文献对比
6. 全局表达指标（补充说明未牺牲整体性能）

## 四、DeepSpatial 改造模块设计

保留 DeepSpatial 的联合状态（位置 + 表达 + 连续类别）流匹配 + 非平衡最优传输框架，重点增强稀有细胞相关部分。

### 模块 A：类型感知的运输与抽样（Type-aware Transport & Sampling）

**目的**：解决稀有细胞进入训练轨迹机会少、损失权重低的问题。

**具体设计**：
- 在局部同类型 + 物理距离限制的支持集上求解非平衡最优传输。
- 对稀有类型显式提升来源边际概率（或与有效来源均匀分布混合）。
- 独立的类别风险加权：稀有类型轨迹在损失中获得更高权重。
- 来源边际校正与类别损失权重可分开控制，便于消融。

**关键公式思想**：
\[
Q_{\text{corrected}} = (1-\lambda) Q_{\text{OT}} + \lambda Q_{\text{uniform on valid sources}}
\]
并对稀有类型额外乘以类别权重 \(w_k > 1\)。

### 模块 B：双端生态位条件残差（Dual-end Niche Residual）

**目的**：利用局部微环境信息修正稀有细胞的状态演化。

**输入特征**（配对两端分别提取）：
- 邻域细胞类型组成直方图
- 邻域基因表达统计（均值/标准差或 marker 相关）
- 相对几何矩（一阶、二阶）
- 有效邻居数与缺失标志

**网络结构**：
- 基础速度场（原 DeepSpatial/GiT）保持不变或轻量微调。
- 新增条件残差网络：将当前状态编码与双端生态位编码融合，预测位置、表达、类别三个模态的速度残差。
- 零初始化残差输出层，训练初期总速度等于基础速度。

### 模块 C：Marker 引导的一致性约束（Marker-guided Consistency Loss）

**目的**：直接连接技术指标与生物学身份，构建成本极低、信号极强。

**损失设计**：
- 对每个稀有类型的已知 marker 基因，计算生成结果与真实（或可见统计）的空间分布相关性损失。
- 类型内 marker 表达一致性损失。
- 可与主重建损失加权组合，权重较小但稳定。

**优势**：不依赖全转录本，只使用面板内已有的 marker，完全适配成像数据。

### 模块 D：残差约束与生成门控（Constraint & Gating）

**目的**：防止残差破坏常见细胞，同时保证稀有细胞有足够修正空间。

- 分模态幅度上限（位置、表达、类别使用不同尺度）。
- 来源类型门控：稀有类型允许更大残差幅度。
- 锚点正则：在原始运输路径附近约束残差，维持整体分布稳定。
- 生成阶段可对稀有类型设置独立数量预算或采样门控。

### 模块组合推荐

| 阶段 | 启用模块 | 目标 |
|------|----------|------|
| 快速验证 | A + C | 先解决抽样与身份问题 |
| 完整方法 | A + B + C + D | 全流程增强 |
| 消融 | 逐一去掉 A/B/C | 证明贡献 |

## 五、实施优先级与注意事项

### 5.1 实施顺序建议
1. 实现并验证新评价指标（尤其是 One-to-one Matching、Precision、Marker Spatial Correlation、Local Composition KL）。
2. 在 DeepSpatial 上加入模块 A（类型感知运输与加权），观察稀有召回与 Matching Distance 变化。
3. 加入模块 C（Marker 损失），重点看 Marker Spatial Correlation 提升。
4. 加入模块 B（生态位残差）与模块 D（约束），完善局部微环境恢复。
5. 完成消融与生物学案例。

### 5.2 关键注意事项
- 稀有类型定义仅使用可见训练切片的丰度，隐藏切片标签只用于最终评价。
- Marker 列表必须来自公开文献或标准 atlas，避免循环论证。
- 生成预算与真实数量脱钩评价，必须同时报告 Count Error 和 Precision。
- 所有邻域统计、基因尺度、类型频率仅从可见切片估计，防止信息泄漏。

### 5.3 预期贡献点（论文可强调）
- 针对三维重建中稀有细胞系统性低估问题，提出类型感知运输 + 生态位条件 + Marker 约束的完整解决方案。
- 建立更有区分度的稀有细胞评价体系（位置匹配 + 精确率 + Marker 空间相关 + 局部组成）。
- 在不依赖高成本全基因组调控网络的前提下，实现与生物学发现直接相关的稀有群体恢复。

---

## 六、总结

本方案继续以 DeepSpatial 为骨干，重点解决稀有细胞在训练参与、局部状态修正和生物学身份保持上的不足。通过更严格的评价指标、更匹配数据现实的先验（Marker + 生态位）以及模块化改造，形成从技术提升到生物学解释的完整闭环。
